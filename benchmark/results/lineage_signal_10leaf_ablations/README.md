# 10-Leaf Ablation Study

This directory contains the RegArch ablation study for the same
`lineage_signal_10leaf` simulation data used by the primary benchmark.

It is intentionally separate from the cross-method benchmark outputs in
`../lineage_signal_10leaf_benchmark/`.
